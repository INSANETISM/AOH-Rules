# Bases Must Be Raidable

All bases must be designed in a way that allows other players to reasonably raid them.

---

## Prohibited Base Designs

Players may not create:

- Impossible base designs.
- Bases that rely on exploits.
- Structures specifically designed to prevent all access.

---

## Fair Gameplay

Base building should provide protection while still allowing legitimate raid gameplay.
