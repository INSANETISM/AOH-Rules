# Lag Issues

Players are responsible for ensuring their builds do not create significant server performance issues.

---

## Staff Inspections

If a base creates significant:

- Server lag
- Frame drops
- Performance issues

Staff may perform a base inspection.

---

## Build Adjustments

After inspection, staff may provide required build adjustments to improve server performance.

Players are expected to cooperate with changes requested by staff.
